# Новотаиидане: общая основа с Новокушанами и классовая наука v1

**Разбор22 октября:** получен [новый пользовательский черновик на65 исследований](../reference/NEOTAIIDAN_RESEARCH_DRAFT_2026-10-22.txt), [сравнение с HW2 Classic и аудит служебных кораблей обеих рас](NEOTAIIDAN_RESEARCH_REVIEW.md). Уже согласовано: **общий модуль → шасси класса → профильный модуль → корабли**; **потеря секции сохраняет открытые проекты/бонусы, но закрывает дальнейшую науку её ветки до восстановления**. Детали остальных связей/эффектов ещё согласуются; научная реализация Новотаиидан не установлена. Принято направление использовать корабли Новотаиидан и обычных вэйгров для сюжетного флота Радаа без отдельной полноценной игровой расы Радаа. Историческая спецификация ниже не отменяет этот новый черновик и зафиксированные уточнения.

**Уточнение21 октября:** новое подробное инженерное дерево реализуется только у Новокушан. Новотаиидане сохраняют текущую пробу без науки до подготовки их классового дерева. Исследовательская станция остаётся только им; условие открытия «генератор гиперпространства» зафиксировано для их будущей науки, не привязано к недоступному новокушанскому исследованию. [Текущая научная фаза](../NOVOKUSHAN_RESEARCH_TREE.md).

20 октября 2026 года, по решению Дмитрия. **Добавлена вторая проектируемая раса — Новотаиидане. Начальная схема копирует балансную основу Новокушан, использует таииданские прототипы и отличается устройством науки. Дополнительно вызывается штатная исследовательская станция вместо верфи HW2. Это спецификация; игровые определения и установленный мод не менялись.**

Общая база: [Новокушане](NOVOKUSHAN_DESIGN.md). Сравнение научных направлений и разведка SU: [NOVOKUSHAN_RESEARCH_MODULES.md](NOVOKUSHAN_RESEARCH_MODULES.md).

## Что означает «копией»

Начальные цены, отряды, роли и ограничения наследуем из принятой схемы Новокушан. Отдельные отклонения вводим явным решением, поэтому не пересчитываем стоимость всей расы лишь из-за другого набора исследовательских веток.

| Параметр | Общая начальная схема |
|---|---|
| Истребители | 14 юнитов; шаблон отрядов 5/5/5/5 для соответствующих ролей. |
| Корветы | 12 юнитов; шаблон 4/3/3/1, минный одиночный, минных ≤5. |
| Фрегаты | 21 корпус; исходные подлимиты поддержки 4 и специального фрегата 2 как шаблон. |
| Крупные корабли | 15 вместе; лёгкие эсминцы ≤10 вместе, тяжёлые ≤5, носители ≤4. |
| Генераторы / наука | 18 вместе, каждый тип ≤6; научная сборка до шести секций. |
| Защитники | Отдельные ≤4 групп по 4 аппарата. |
| Инженеры | Абордажники и ремонтники ≤20 вместе. |
| Экономика | Ресурсеров ≤20, контроллеров ≤4. |
| Цена носителя | 4000 RU. |
| Лёгкий / лёгкий ракетный / тяжёлый эсминец | 1350 / 1500 / 2800 RU по общей проектной настройке. |
| Производство носителя | Последовательно, классический охват; сверхтяжи и пока контроллер — только на Материнском. Дополнительная станция тоже ограничена кораблями до фрегатов включительно. |
| Исследования | Одна общая очередь игрока; секции открывают свои ветки и вместе ускоряют текущее исследование по HW2. |
| Support Units | Разведка наследуется; веса SU, запас и замена текущих капов ещё не утверждены. |

Остальные уже принятые цены из таблицы Новокушан — исходные цены соответствующих ролей; черновые цены там остаются черновыми и здесь. Имена собственных исходных таииданских кораблей сохраняются для сверки. Копирование схемы не доказывает совпадение оружия и моделей двух исходных рас.

Из 28 кушанских прототипов у 26 есть одноимённый `tai_*` файл. Прямых `tai_cloakedfighter` и `tai_dronefrigate` в локальной штатной базе нет. **Роли этих двух слотов пока не переименовываем автоматически в Defense Fighter/Field Frigate**: уникальные таииданские проекты и соответствие общей сетке требуют отдельного решения. Это не препятствует принятию общей экономики и шести научных направлений. Финальный поимённый состав Новотаиидан ещё нужно сверить.

## Принятые шесть научных секций

Дмитрий отдельно подтвердил: **научная сборка сохраняется, станция добавляется к ней**. Шесть модулей ниже относятся к сборке исследовательских кораблей. Они не перенесены на станцию.

| № | Принятое название | Проект содержимого ветки |
|---|---|---|
| 1 | Общий исследовательский модуль | Общие технологии, экономика, служебные корабли, генераторы и сенсоры; распределение конкретных работ ещё проектируется. |
| 2 | Истребительный модуль | Открытия и улучшения истребителей: корпуса, двигатели, оружие и способности класса. |
| 3 | Корветный модуль | Открытия/улучшения корветов, включая минные технологии. |
| 4 | Фрегатный модуль | Открытия/улучшения фрегатов и специальных фрегатных способностей. |
| 5 | Модуль сверхтяжёлых кораблей | Открытия/улучшения эсминцев и носителя. |
| 6 | Платформенный модуль | Платформенная ветка; текущая база для неё — группы Защитников. Новые типы платформ этим решением не добавлены. |

Утверждены состав шести направлений и одна очередь. Подробное содержимое общего модуля, зависимости между классами и цены/времена отдельных работ пока предложены к расчёту. Прежний вариант «истребители / корветы / фрегаты / сверхтяжи / утилиты / генераторы» заменён пользовательским списком выше.

Связи между технологиями сохраняются через RequiredResearch, профильный допуск — через RequiredSubSystems. Общий модуль можно использовать как начальную научную основу, но требование иметь его для каждой последующей работы ещё не назначено автоматически. Строительство самой научной сборки должно оставаться доступным без циклического требования уже иметь её собственную технологию.

В локальной основе есть `tai_researchship` и `tai_researchship_1…5`, использующие те же шесть скрытых HW1_ResearchModule. Нужно проверить свободный выбор следующей специализации вместо штатного последовательного открытия секций. Технические ID не меняем.

Ускорение наследуем из общей схемы: `t=T/√(n+1)`, n — действующие научные секции сборки. Одновременно исследуется одна работа. При шести секциях скорость примерно ×1,87 относительно одной. Учёт пристыкованных секций остаётся будущей движковой проверкой.

Предложен [общий пакет постройки без исследований](NOVOKUSHAN_RESEARCH_MODULES.md#предложение-базовая-постройка-без-исследований): лёгкий истребитель, ресурсер, переработчик, ремонтник, пробка и все шесть специализаций научных секций. Это ещё не принятое изменение; дополнительная станция в нулевой пакет не включена. Условия стартовых флотов кампании рассматриваются отдельно.

## Дополнительная вызываемая исследовательская станция

**Принято:** использовать штатную таииданскую одиночную исследовательскую станцию `tai_researchstation` как дополнительно вызываемый производственный объект на месте идеи верфи HW2. **По последнему уточнению Дмитрия проём ограничивает её строительство кораблями до фрегатов включительно.** Функции сверх обычного производства кораблей будем обдумывать позже. Шестисекционная научная сборка сохраняется отдельно. В роли вызываемого производственного центра используется эта станция.

В локальном HWRM-определении станции найдены:

| Свойство исходного объекта | Наблюдение |
|---|---|
| Корпус | `tai_researchstation`, штатная модель. |
| Движение | mainEngineMaxSpeed=0, thrusterMaxSpeed=0. |
| Прочность | maxhealth=220000. |
| Исходные поля стоимости/времени | buildCost=3000, buildTime=600. Это исходные поля SP-объекта, не принятый новый ценник. |
| Строительство кораблей | В файле нет CanBuildShips. |
| Научные модули | В файле нет StartShipHardPointConfig и isResearch. Само название не даёт объекту работающую лабораторию. |
| Гиперпространство | Есть запись HyperSpaceCommand с начальным флагом 0; готовность новой команды вызова этим не доказана. |

В качестве технического образца вызова изучена штатная запись Hgn_Shipyard в def_build: Type=Ship, RequiredShipSubSystems=Hyperspace. Для станции потребуется отдельно подготовить строительную запись/допуск и появление через гиперпространство. Добавление способности прыжка объекту само по себе не заменяет всю цепочку вызова.

**Базовая роль станции выбрана: обычное производство кораблей до фрегатов включительно.** Сверхтяжи, включая все эсминцы и носители, остаются Материнскому кораблю. Контроллер пока также только на Материнском; список других служебных кораблей станции сверяем отдельно. Прежняя трактовка полной производственной номенклатуры верфи снята. Ограничение станции принято по оценке Дмитрием размера проёма; это не результат нашего движкового теста. Производственные способности, выпуск и очереди надо подготовить отдельно: в исходном SP-объекте они отсутствуют.

**Дополнительные функции отложены:** продвинутая наука, особые исследования, бонусы и прочее сейчас не назначаются. В частности, станция не получает автоматически ещё шесть лабораторий или седьмой источник ускорения науки. Цена, время вызова, лимит, условия доступа и место в существующих пулах тоже ещё не рассчитаны. Сам факт добавления станции не увеличивает согласованные капы молча.

## Различие двух рас

| | Новокушане | Новотаиидане |
|---|---|---|
| Разделение науки | Инженерные направления с киитами. | Классы кораблей плюс общий и платформенный модули. |
| Научная инфраструктура | Шестисекционное кольцо. | Сборка из шести исследовательских секций. |
| Очередь | Одна общая. | Одна общая. |
| Дополнительная станция | Не добавлена. | Вызываемая tai_researchstation, производство до фрегатов; научная сборка отдельно. |
| Начальный баланс | Принятая общая основа. | Копия общей основы, будущие отличия явные. |

Английское имя новой расы пока рабочее: Neo-Taiidan / Neo-Taiidani. Принято русское «Новотаиидане», с двойным «ии». Исходные EN/RAW и технические ID не переписываются.

Статические свидетельства: [mechanics-evidence.json](../../local/novokushan/mechanics-evidence.json), [инструмент чтения](../../tools/audit_novokushan_mechanics.py). Игра и лаунчер не запускались; переноса новой расы в релиз пока нет.

Уточнение общей основы от 20 октября: тяжёлый эсминец имеет **90000 HP / HeavyArmour**. Полные подписи вместо разговорных сокращений сверяются по общему глоссарию.

Общие правки интерфейса от 20 октября: тяжёлый эсминец — значок Parallelogram; инженерные корветы в Platform, генераторы/сенсорная батарея в NonCombat. Используются существующие вкладки и иконки. Для отрядов оставлена штатная Batch_delta.

Актуальная категория **Платформы**: tai_defender и tai_defensefighter делят общий лимит4отряда. Защитный истребитель больше не в пуле Fighter, строительство — во вкладке Platform вместе с Защитником и инженерными корветами. Инженеры сохраняют свой лимит20. Численность защитного истребителя пока5, цена700RU. Подлимиты поддержки/специальных фрегатов и генераторов визуально сгруппированы под соответствующими общими капами.

Последняя настройка: защитных истребителей3 вместо5. Общая настройка обеих рас: лёгкий истребитель5/450RU/20HP/урон0.6, Перехватчик5/550RU/40HP/урон1.2; лёгкий корвет4/600RU/ромб1+2+1; ЗащитникиСтена2x2. Тяжёлый эсминец — реальный класс HW2Destroyer (SmallCapitalShip/Capital), кап5; отсутствие линейных крейсеров компенсирует отдельный дополнительный кап10 лёгких эсминцев. Все новые ТО/боевые параметры описаны в FIGHTER_BALANCE.md.
