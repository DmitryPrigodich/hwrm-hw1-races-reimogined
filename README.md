# hwrm-hw1-races-reimogined

Самостоятельный второй слой: Новокушане и Новотаиидане на закреплённой основе hwrm-mp-patch. Кампанию добавляет hwvr-to-hwrm-mod. История этого репозитория начинается с проверенного выделения текущих рас23октября2026; принятые параметры сохранены.

data/ — действующие определения рас, собственная наука/стройка, строи, RU/EN и независимые карты пробы флота. design/ — дерево исследований, принятые коэффициенты и проверки защищённых параметров. tools/legacy/ сохраняет прежние генераторы как материал дальнейшего переноса: они ещё связаны со старой структурой и не являются активной сборкой. Авторитетный вход текущей независимой сборки — data/.

```powershell
git submodule update --init --recursive
python -m pip install -r requirements.txt
python tools/build.py --package
```

Зависимость dependencies/mp-patch и dependencies.lock.json фиксируют одну ревизию общей основы. HWRM_ASSET_CACHE указывает на локальный кэш; пути/хеши нужных моделей и миниатюр перечислены в assets.json. Ассеты остаются вне Git. Манифест local/source.json указывает на рабочие исходники в коротком каталоге локального кэша (обход ограничения путей Archive.exe). Выпуск — local/HWRMHW1Races-release. Никакого автоматического запуска/установки.

Взяты существующие параметры рас: тяжёлые эсминцы90000HP/HeavyArmour, собственные отряды, формы, цены, наука/стройка. Категории HW2 и9частных оружейных профилей сохранены. Новокушанская наука57платных+71автоматический эффект; научная переработка Новотаиидан остаётся отдельной задачей согласования. Кушанские/таииданские технические IDs пока стабильны; VRCFleetPreview — сохранённый ID тестовых карт, не сюжетная кампания.

Нативный баланс, оружейное поведение, науки/стыковки/save-load/MP этим выделением не подтверждены. Общие ошибки исправляются в базовом репозитории, особенности новых рас — здесь, миссии/история — в кампанийном.

Закреплена база fd3e7c1 с исправленным data TOC; сборка добавляет hw1_races.dat в штатный реестр, проверяет 254 RU/EN записи UTF16/CRLF. Баланс и дерево не менялись.
